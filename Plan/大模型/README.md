## 一、上下文压缩

### 现状
- 无上下文压缩——`sessionMessages` 数组无限增长
- 主 Agent 循环限制 25 轮，子 Agent 限制 10 轮
- 超过限制直接返回 "(max iterations)"，无中间保存

### 问题
- 长会话必然爆 token（模型上下文窗口有限）
- 无记忆跨会话——每次启动都是全新对话
- 工具调用结果（特别是大文件内容）迅速填满上下文

### 待做
- [ ] **滑动窗口**：保留最近 N 轮完整内容，超出部分压缩为摘要
- [ ] **智能摘要**：LLM 自动生成对话摘要，保留关键决策、待办事项、已修改文件列表
- [ ] **分层压缩**：
  - 第 1 层：工具输出截断（当前已有部分，如 `briefResult()` 取首行）
  - 第 2 层：旧轮次对话摘要化
  - 第 3 层：大文件内容只保留"改动部分"而非全量
- [ ] **关键信息锚点**：用户明确说"记住这个"的内容永不压缩
- [ ] **上下文预算感知**：实时估算 token 用量，接近上限时主动压缩
- [ ] **跨会话记忆**：利用 ~/.mycoder/MYCODER.md 作为持久记忆层
- [ ] **上下文恢复**：被压缩的内容在需要时可回溯（存储完整历史到文件）

### 设计参考
- Claude Code 有上下文压缩子系统（`context-compression-plan.md` 已存在于 Plan/）
- 可参考 mem0 / MemGPT 等开源项目的分层记忆架构
- Agent 引擎（agent.ts）的 sessionMessages 需要改造为"活跃窗口 + 压缩存储"双轨

### 关联
- `Plan/context-compression-plan.md`（已有计划文档）
- agent.ts 的 `sessionMessages` 和 `run()` 方法
- Machain 项目的记忆地图设计

## 二、大模型稳定连接

### 现状
- 两个 Provider：Anthropic（anthropic.ts）和 OpenAI/DeepSeek（openai.ts）
- 无重试机制——一次网络抖动就报错
- 无 Provider 故障切换
- 无速率限制处理

### 待做
- [ ] **自动重试 + 指数退避**：
  - 网络错误（ECONNREFUSED、ETIMEDOUT、ENOTFOUND）：最多 3 次重试
  - 服务端错误（5xx）：最多 3 次重试，间隔 1s/2s/4s
  - 速率限制（429）：等待 Retry-After 头后重试
  - 客户端错误（4xx 除了 429）：不重试，直接报错
- [ ] **Provider 故障切换**：
  - 主 Provider 连续失败 N 次 → 自动切换到备选 Provider
  - 用户可配置主备关系（如 Anthropic 主、DeepSeek 备）
  - 切换时通知用户
- [ ] **速率限制（Rate Limiting）**：
  - 本地令牌桶限流，避免触发 API 的 429
  - 并发请求数上限（当前 Agent + 子 Agent 的 LLM 调用可能同时发生）
- [ ] **连接超时控制**：
  - 连接超时：10s
  - 读取超时：60s（长思考模型可能需要更久）
  - 可配置
- [ ] **错误分类与用户友好提示**：
  - 401/403 → "API key 无效或过期，请检查 ~/.mycoder.json"
  - 429 → "请求太频繁，正在等待..."
  - 5xx → "服务端暂时不可用，正在重试 (第 N 次)..."
  - 网络错误 → "网络连接失败，请检查网络和代理设置"
- [ ] **健康检查**：启动时对配置的 Provider 发一个轻量请求（如 model list），确认可用
- [ ] **流式响应支持**：当前是完整响应后一次性返回，改为 SSE 流式——减少感知延迟 + 长响应不容易超时

### 设计参考
- 当前 provider.ts 只有 41 行，LLMProvider 接口需扩展 retry/health 方法
- openai.ts（100 行）和 anthropic.ts（53 行）需重构为带重试的 wrapper
- 网络稳定连接与 Tool 层的网络稳定连接可共享底层重试/超时工具函数

### 关联
- `src/llm/types.ts`：LLMProvider 接口定义
- `src/llm/openai.ts` / `src/llm/anthropic.ts`：Provider 实现
- `Plan/tool/`：Tool 层的网络稳定连接（底层 HTTP 重试可共用）
