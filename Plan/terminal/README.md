## 输入输出队列方案评估

**用户提出**：维护一个串行队列，输入输出按序处理，起到缓冲作用。

**评估**：
- ✅ 解决双向碰撞（输入回显和程序输出同时写入 PTY 导致渲染管线被重入）
- ❌ 不解决根本问题（超长行触发布局递归——队列不改变内容的形态，只改变时序）
- 结论：队列是**好的辅助机制**，配合折行构成完整防御。但不是治本方案本身。

## 最终架构

```
Mycoder 输出
  → output-wrapper.ts（边界折行——治本）
  → 输出队列（时序保护——辅助）
  → PTY → Terminal（不再收到超长行 → 布局正常收敛 → 不崩）
```
