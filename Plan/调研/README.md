# 调研

> Claude Code 源码与运行机制的专题调研集。每一项调研独立建文件夹，调研内容放入其中。

---

## 规范

1. **每项调研一个文件夹**。文件夹名用中文短描述，如 `agent集群`、`token计数`。

2. **每个文件夹里先放 README**，介绍本次调研的背景、目标、关键结论。

3. **再放具体内容**。多文件时按主题拆分，单文件直接放。

4. **引用源码时标注文件路径和行号**。所有 CC 源码路径相对于 `study/claude-code/claude-code-main/src/`。

5. **调研完成后更新此索引**。
